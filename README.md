# Pokémon Lookup 🔍

A simple and stylish web app that lets users search, explore, and favorite Pokémon using the [PokéAPI](https://pokeapi.co/). Built with HTML, CSS, and JavaScript.

## 🌐 Live Site

Check it out here: [https://your-username.github.io/your-repo-name](https://your-username.github.io/your-repo-name)

## ✨ Features

- 🔎 Search Pokémon by name or ID
- 🎲 "Random Pokémon" button for quick exploration
- 🌱 Evolution chain display (with images)
- ❤️ Favorite Pokémon with localStorage persistence
- ❌ Unfavorite Pokémon
- 🎨 Clean UI with background image and type styling
- 📱 Fully responsive and mobile-friendly

## 🧠 How It Works

The app fetches data from the public [PokéAPI](https://pokeapi.co/) — no API key required. Data is fetched using JavaScript's `fetch()` function and rendered into the DOM dynamically.

## 🛠️ Setup Instructions

No credentials or setup required. Just open `index.html` in your browser, or view the live version.

To run locally:
1. Clone the repository
2. Open `index.html` in your browser

## 🔐 Credentials

This project uses a public API and **does not require credentials**. No API keys are exposed or needed.
